# Skills

A public catalog of agent skills maintained by [Marc](https://github.com/marctheshark3), with pinned source links, downloadable source archives, applicable licenses, and tool requirements. Each upstream repository remains its canonical source.

The first catalog contains 19 packages across seven selected public repositories. Eighteen have explicit reuse licenses; one is listed for reference only. This is a curated starting inventory.

## Browse the catalog

Downloads are full repository ZIPs pinned to the recorded commit. Choose the named skill directory and preserve its resources, license, and notices. Download availability records source distribution checks; model and host behavior still need local validation. Full requirements, SHA-256 values, and installation notes are in [catalog.json](catalog.json) and [SOURCES.md](SOURCES.md).

## Recreate locally

When local policy permits an external behavior brief but an imported implementation is unsuitable, an approved local model can use the brief to build a local variant. A useful brief states activation conditions, outputs, constraints, required capabilities, permitted substitutions, and observable acceptance examples. The local result needs its own validation and provenance.

Many skills are already instructions alone. This option adds a behavioral specification and local adaptation; it does not establish equivalence or bypass an organization's normal rules for prompts, generated code, or licensing. The catalog records the brief independently from the source package. Upstream entries without a reviewed brief keep this option unavailable.

## Experimental coordinator

The original [task-coordination draft](skills/task-coordination/SKILL.md) selects relevant available skills, requests bounded independent work when useful and permitted, and keeps one parent responsible for integration and verification. Simple or tightly coupled work stays serial.

Its standalone [creation brief](recipes/task-coordination.txt) can be inspected alongside the [evaluation plan and observations](EVALUATION.md). The draft and brief are MIT-licensed. Automatic discovery, live delegation, and locally recreated variants have not been independently tested. They are not presented as validated catalog adoption options.

## Compatibility and checks

List capabilities first and record observed model/version/harness results after actual trials. Untested combinations remain unknown. This catalog publishes no model rankings.

For development, use Python 3.10 or newer, install [requirements-dev.txt](requirements-dev.txt), and run:

```sh
python3 checks/validate_catalog.py
```

The check validates the public catalog, the explicitly unavailable pre-publication example, local references, and schema contract cases. It does not fetch source URLs, install skills, or execute catalog content. Validate original skill packages with the available Skill Creator validator. See [AGENTS.md](AGENTS.md) for contribution requirements.
